# CVC Input

Card security code (CVV/CVC) input.

## Basic Usage

```tsx
<Input name='cvc' type='cvc' placeholder='123' maxLength={3} />
```

## With Label

```tsx
<Input name='cvc' type='cvc' label='CVC' placeholder='123' />
```

## Props

- 3-4 digits
- Numeric keyboard
- Secure entry
