# Expire Date Input

Credit card expiration date input with MM/YY formatting.

## Basic Usage

```tsx
<Input name='expiry' type='expireDate' placeholder='MM/YY' />
```

## With Label

```tsx
<Input name='expiry' type='expireDate' label='Expiry Date' placeholder='12/25' />
```

## Props

- MM/YY format
- Auto-formatting
- Numeric keyboard
