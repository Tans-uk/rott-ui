# IBAN Input

IBAN (International Bank Account Number) input with automatic formatting.

## Basic Usage

```tsx
<Input name='iban' type='iban' placeholder='TR00 0000 0000 0000 0000 0000 00' />
```

## With Label

```tsx
<Input name='iban' type='iban' label='IBAN' placeholder='Enter your IBAN' />
```

## Features

- Auto-formatting with spaces
- Country code validation
- Uppercase conversion
