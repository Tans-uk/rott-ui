# Numeric Input

Input that accepts only numeric values.

## Basic Usage

```tsx
<Input name='quantity' type='numeric' placeholder='0' />
```

## With Label

```tsx
<Input name='age' type='numeric' label='Age' placeholder='Enter your age' />
```

## Features

- Numeric keyboard
- No decimals
- Integer values only
