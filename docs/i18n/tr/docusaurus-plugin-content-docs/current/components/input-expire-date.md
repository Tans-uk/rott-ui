# Expire Date Input

MM/YY biçimlendirmeli kredi kartı son kullanma tarihi input'u.

## Temel Kullanım {#basic-usage}

```tsx
<Input name='expiry' type='expireDate' placeholder='MM/YY' />
```

## Label ile {#with-label}

```tsx
<Input name='expiry' type='expireDate' label='Expiry Date' placeholder='12/25' />
```

## Props {#props}

- MM/YY formatı
- Otomatik biçimlendirme
- Sayısal klavye
