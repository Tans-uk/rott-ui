# IBAN Input

Otomatik biçimlendirmeli IBAN (Uluslararası Banka Hesap Numarası) input'u.

## Temel Kullanım {#basic-usage}

```tsx
<Input name='iban' type='iban' placeholder='TR00 0000 0000 0000 0000 0000 00' />
```

## Label ile {#with-label}

```tsx
<Input name='iban' type='iban' label='IBAN' placeholder='Enter your IBAN' />
```

## Özellikler {#features}

- Boşluklarla otomatik biçimlendirme
- Ülke kodu validation'ı
- Büyük harfe dönüştürme
