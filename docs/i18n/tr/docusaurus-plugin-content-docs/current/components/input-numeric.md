# Numeric Input

Yalnızca sayısal değer kabul eden input.

## Temel Kullanım {#basic-usage}

```tsx
<Input name='quantity' type='numeric' placeholder='0' />
```

## Label ile {#with-label}

```tsx
<Input name='age' type='numeric' label='Age' placeholder='Enter your age' />
```

## Özellikler {#features}

- Sayısal klavye
- Ondalık yok
- Yalnızca tam sayı değerler
